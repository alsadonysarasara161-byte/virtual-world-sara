العالم الافتراضي - نموذج أولي أونلاين


ما الموجود:
- صفحة إنشاء اسم وشخصية (اختيار لون البشرة/الشعر/الملابس/قصة الشعر)
- مدينة 3D بسيطة
- تحكم لمس موبايل وكاميرا بالسحب
- سيرفر Socket.IO يزامن مواضع اللاعبين عند دخولهم نفس رابط الاستضافة
- نقطة فحص /health

ما ليس موجودًا بعد:
- موديلات بشرية واقعية عالية الجودة/أنيميشن احترافي (الشخصيات الحالية إجرائية بسيطة)
- حسابات حقيقية أو حفظ الشخصيات في قاعدة بيانات
- قيادة السيارة، دخول المباني، المتجر، الألعاب، اقتصاد دائم (تفاعلات توضيحية)
- تأمين/تحديد غرف أو حماية ضد الغش

تشغيل على الكمبيوتر:
1) تثبيت Node.js LTS
2) فك الضغط
3) داخل المجلد شغّل: npm install
4) ثم: npm start
5) افتح http://localhost:3000

نشر السيرفر (مثال Render):
- ارفع مجلد المشروع إلى GitHub
- أنشئ Web Service على Render من مستودع GitHub
- Build Command: npm install
- Start Command: npm start
- لا تضف متغير PORT؛ Render يمرره تلقائيًا
- بعد النشر افتح رابط الخدمة من هاتفك وشارك الرابط مع حسين

تنبيه: نموذج أونلاين أولي. استخدم خدمة استضافة تدعم WebSockets. لا تستخدمه لجمع بيانات حساسة؛ لا يوجد تسجيل دخول حقيقي.
